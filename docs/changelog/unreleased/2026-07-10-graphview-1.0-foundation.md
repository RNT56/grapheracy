# Graphview 1.0 foundation

- Add stable quality, integration, end-to-end, performance, security, and release verification commands.
- Add an architecture regression gate and a proof-based Graphview 1.0 upgrade ledger.
- Replace the bounded SVG-first graph path with incremental Graphology/Sigma 2D rendering, persistent viewport bounds,
  renderer-specific raw budgets, lazy Three.js parity, deterministic large-layout seeding, and WebGL-loss fallback.
- Add browser-enforced 100k/500k clustered overview, 5k/20k and 20k/50k frame budgets, mobile renderer lifecycle,
  nonblank pixels, selection recovery, canonical V1 viewport requests, and paged/filterable accessible graph data.
- Standardize the Sigma and Three.js scene inputs and runtime metrics, and harden startup plus recovery through a
  forced no-WebGL acceptance path that preserves the SVG and list/table equivalents.
